# HSE OPS AI — Toolbox Talk Framework

## Purpose

Toolbox talks are mandatory pre-task safety briefings conducted by a supervisor with the work crew before any non-routine activity. HSE OPS AI can generate a customised toolbox talk in seconds, calibrated for the specific activity, location, and crew.

## Why AI-Generated Toolbox Talks?

**Problem**: Generic toolbox talks are ineffective. "Be careful with electricity" does not resonate. "Today we are replacing the submersible pump in the Bonga FPSO J-10 well cellar — here are the 4 specific hazards" does resonate.

**Solution**: AI retrieves relevant NEPL procedures, extracts activity-specific hazards, and generates a toolbox talk in plain language at the right reading level for the crew.

## Toolbox Talk Structure

A generated toolbox talk contains 6 elements:

### 1. Title (1 line)
Specific to the activity: "Toolbox Talk: Hot Tapping on 6-inch Gas Line, Okono Platform"

### 2. Discussion Points (5–8 items)
Narrative points the supervisor covers conversationally. Not bullet points to read — talking points to discuss.

Example for tank cleaning:
- "Today we're entering Tank T-102 on the terminal. This is a confined space permit job."
- "The tank has been purged with nitrogen — what does that mean for our O₂ levels?"
- "We've done the gas test — what are the levels we need to see before anyone enters?"

### 3. Hazards (4–6 items)
Specific to the activity and location — not generic.

Example:
- `Oxygen deficiency in tank atmosphere (nitrogen purge residual)`
- `H₂S release from crude oil residue on tank floor`
- `Slippery surfaces from waxy crude deposits`
- `Heat stress — tank temperature may be elevated`

### 4. Controls (4–6 items)
One-to-one with hazards where possible.

Example:
- `Continuous O₂ and H₂S monitoring throughout entry (gas detector with audible alarm)`
- `SCBA staged at entry point — standby person trained and equipped`
- `Non-sparking footwear, non-slip socks over boots`
- `Work rotation — max 30 minutes per entrant, rest in fresh air`

### 5. Quiz Questions (3–5 items)
Check crew understanding — supervisor asks, waits for answers.

Example:
- "What level of H₂S would cause us to stop work and evacuate immediately?"
- "If your gas detector alarm goes off while inside the tank, what do you do first?"
- "Who is the standby person today and where will they be positioned?"

### 6. Emergency Information
- Nearest muster point
- Emergency contact / radio channel
- Location of nearest first aid kit
- Location of nearest SCBA rescue set

## Data Model

```typescript
interface ToolboxTalk {
  id: string;
  user_id: string;
  title: string;
  activity?: string;
  location?: string;
  crew_size: number;
  duration_minutes: number;
  discussion_points: string[];
  hazards: string[];
  controls: string[];
  questions: string[];
  environmental_conditions?: string;
  status: 'draft' | 'conducted';
  conducted_at?: string;
  ai_generated: boolean;
  created_at: string;
}
```

## Generation Flow

```
User fills form: activity, location, crew size, environmental conditions
    ↓
POST /functions/v1/generate-toolbox-talk
    ↓
Edge Function: retrieve top 3 procedure chunks for the activity
    ↓
Build prompt → GPT-4o call
    ↓
Parse JSON response
    ↓
Save to toolbox_talks table (status: 'draft')
    ↓
Display to user for review
    ↓
User can edit any field before conducting
```

## Conducting a Toolbox Talk

1. Supervisor reviews generated talk (edit if needed)
2. Presents to crew verbally (not just reads it)
3. Asks quiz questions — records who answered correctly
4. Marks talk as 'conducted' in the app
5. All crew members acknowledge digitally (or supervisor records names)
6. `conducted_at` timestamp recorded

Records are retained for minimum 3 years (NEPL requirement).

## PDF Export

Toolbox talk exports to a clean PDF for physical display at the work site:
- Header: NEPL logo, title, date, location, crew size
- Section 1: Discussion points (printed for supervisor to hold)
- Section 2: Hazards table + controls
- Section 3: Quiz questions
- Sign-off section: lines for attendee names and signatures
- Footer: "Generated by HSE OPS AI | Based on NEPL approved procedures"

## Quality Metrics

A high-quality toolbox talk:
- Contains at least one location-specific hazard (not generic)
- Controls map to the NEPL hierarchy of controls
- Quiz questions test comprehension (not just recall)
- Duration estimate is realistic (15–20 min for standard, 25–30 min for complex jobs)
- Language is at Grade 8 reading level or simpler (accessible to all crew)
